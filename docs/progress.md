## 冷启动解析算法

1. 读上面「日志」表的**最后一行**。
2. 下一个 Day = 该行 Day + 1；表为空则 Day = 1。
3. 用「路线」表把 Day 映射到章与主题。
4. 最后一行状态是 `🔁` → 先重讲那天，不推进。
5. Day 是 7 的倍数 → buffer 日，不上新课。
6. 检查 `vendor/ai-agent-book/chapterN/` 在不在，不在就按 `AGENTS.md` 追加 sparse-checkout。
