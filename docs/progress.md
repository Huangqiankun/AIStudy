## 冷启动解析算法

1. 先读「续课安排」表；有待开展/待续讲项时，使用该行 Day，按对应讲义续上。
2. 没有待安排时，读「日志」表最后一行：`▶` / `🔁` 使用原 Day；`✅` / `⏭` 才取 Day + 1；日志为空从 Day 1 开始。
3. 用「路线」表把 Day 映射到章与主题。Day 是 7 的倍数时为 buffer 日，不上新课。
4. 检查 `vendor/ai-agent-book/chapterN/`，缺失则按 `AGENTS.md` 追加 sparse-checkout。
5. 重讲或续讲在原 lesson 的当前教学区记录。授课结束或中断后追加原 Day 日志，未完成保持待续讲，通过后将安排标为已完成，再推进下一 Day。
